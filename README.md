# 💱 지금 환율은 어떄

![Discord Bot](https://img.shields.io/badge/Discord-Bot-5865F2?logo=discord\&logoColor=white) ![Node.js](https://img.shields.io/badge/Node.js-24.x-339933?logo=node.js\&logoColor=white) ![License](https://img.shields.io/badge/License-EIGHTH80%20CUSTOM-blue)

한국 원화(KRW)를 기준으로 **엔화(JPY), 달러(USD), 위안(CNY)** 환율을 확인할 수 있는 Discord 봇입니다.

## 📌 주요 기능

* `/엔화` — 엔화 환율 확인
* `/달러` — 달러 환율 확인
* `/위안` — 중국 위안화 환율 확인

간단한 슬래시 명령어로 현재 환율 정보를 빠르게 확인할 수 있습니다.

## ✨ 특징

* 🇯🇵 엔화(JPY) 환율 확인
* 🇺🇸 달러(USD) 환율 확인
* 🇨🇳 위안(CNY) 환율 확인
* ⚡ Discord 슬래시 명령어 지원
* 🤖 간편하게 환율 정보를 확인
